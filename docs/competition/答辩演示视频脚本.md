# 答辩演示视频录制脚本（约 4 分钟）

> 配套环境：后端 `http://127.0.0.1:8000`、前端 `http://localhost:3000`（注意浏览器用 `localhost`，不要用 `127.0.0.1`，Vite 只绑定了 IPv6）。
> 演示账号：教师 `teacher_demo/Teacher2026`，学生 `student_demo/Student2026`，管理员 `admin_demo/Admin2026`。
> AI 为真实 DeepSeek，网络波动时单个问答预留 15–30 秒；若超时可跳过该问答并继续。

## 录制准备

1. 用 OBS（推荐）或 Win+Alt+R 录制；分辨率 **1920×1080**，30 fps 足够，输出 MP4。
2. 浏览器开**无痕窗口**并 F11 全屏；Ctrl+Shift+B 隐藏书签栏；开启 Windows 专注助手屏蔽通知。
3. 先把页面全部走一遍（排练），正式录制时鼠标动作放慢；每点一下停顿约 1 秒再说话。
4. 建议**先录画面、后配音**（剪映/PR 对着画面念台词），比边录边讲自然很多。
5. 台词总字数约 950 字，正常语速约 4 分钟；请按实际语速微调。

## 分镜与台词

### 0:00–0:25 开场（首页 + 一句痛点）

画面：先在地址栏输入 `localhost:3000`，滚动首页 Hero 区域，再进入登录页并登录教师账号。

台词：
“大家好，我们带来的是智教通——AI 智能教学辅助平台。教师面对越来越多的数字工具，却不知道自己的教学问题该用哪个；学生知道 AI，也不知道怎样把模糊的问题变成一条可继续的学习路径。智教通解决的，就是这件事。我们先看教师端。”

### 0:25–1:00 教师需求引导（推荐匹配，可解释）

画面：登录教师端 → 需求引导 → 依次选择 文科 / 语文 / 符合“备课与课堂效率”的教学目标 → 停留页面，指出匹配结果与推荐依据。

台词：
“教师端从需求引导开始：选学科、选教学目标，系统用可解释的规则匹配，给出推荐工具和理由。我们特意没有把这种简单匹配包装成 AI 推荐——依据可追溯、可审计，每一行推荐都能说清楚为什么。”

### 1:00–1:45 我的工具与分享（真实数据 + 分享二维码）

画面：进入我的工具，展示“文言文词句翻译助手、古诗词意象赏析助手、数学错题诊断助手”三个工具 → 点开其中一个的预览，向 AI 提一个问题看真实回答 → 展示分享入口与二维码。

台词：
“在我的工具里可以看到已经创建的工具。我们现场试用一下：输入一句文言文，模型给出翻译和重点字词解析，这里调用的是真实的 DeepSeek 模型，只承担文本问答。每个工具都可以一键生成分享链接和二维码，学生扫码即用。”

### 1:45–2:25 教师数据看板（贴近“教学观察”）

画面：进入数据洞察/看板页面，依次指向：使用趋势折线、热门工具排名、使用记录列表；再切换 30 天与单工具筛选。

台词：
“教师最关心的，是工具使用后发生了什么。看板展示了使用趋势、热门工具排名和最近使用记录，也可以按工具和周期切换。这些数据来自真实的使用日志，帮助教师观察数字工具是否真正进入了课堂。”

### 2:25–3:20 学生端：工具广场 + AI 问答

画面：退出登录 → 学生端 → 工具广场：切换文/理分类、搜索关键词 → 点开“古诗词意象赏析助手”，输入问题，展示流式回答。

台词：
“学生端的起点是兴趣。工具广场按文理分类，支持关键词和热度筛选。我们现场问一个学习和探索类问题，可以看到回答是流式生成的。复杂智能体的创建仍然跳转到师大智能体平台完成，平台本身不自建大模型，AI 只做文本问答这一件事。”

### 3:20–3:50 学习轨迹 + 收藏

画面：学生端学习记录/我的学习页面，展示会话历史与问答内容；演示收藏一个工具。

台词：
“每一次提问和使用都会沉淀为学习轨迹，学生可以随时回看问题与回答，也可以收藏感兴趣的工具，后续继续跟进。”

### 3:50–4:05 结尾（架构与工程质量一句话 + 结束语）

画面：可以快速切到 README 的架构图一页（或停留在产品页），同时收尾。

台词：
“技术上，前端 Vue3 + Element Plus，后端 FastAPI 与 MySQL，DeepSeek 仅参与文本问答；项目配有 CI 与前后端测试。智教通不做‘再多一个工具’，而是帮助教师和学生，从‘知道有 AI’走到‘知道什么时候、为什么、怎样用’。谢谢大家。”

## 常见坑

- 浏览器地址必须是 `http://localhost:3000`；`127.0.0.1:3000` 打不开（Vite 只监听 IPv6 回环）。
- 若 AI 回复出现“无法连接 DeepSeek 服务”，重试一次；连续失败就用备用台词：“网络波动，我们看下一个环节”。
- 录制时不要打开开发者工具、不要暴露地址栏中的无痕窗口以外的隐私信息。
- 录完后记得把 `source/backend/.env` 中的 `AI_PROVIDER=deepseek` 改回 `mock` 并清空 Key（见对话记录说明）。
